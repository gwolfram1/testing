# Event RSVP Site

A simple static RSVP page for **Summer Gala 2027**.

## Files

- `index.html` — single-file site, no dependencies

## Usage

Open `index.html` in any browser, or host it on GitHub Pages.

## To enable GitHub Pages

1. Go to repo **Settings → Pages**
2. Set source to **main branch / root**
3. Your site will be live at `https://gwolfram1.github.io/testing/`
